VISITOR SYSTEM — RUN ON YOUR OWN COMPUTER (LOCAL / NODE VERSION)
==================================================================

This is the full Node.js version (visitor form + admin dashboard +
real WhatsApp Web login), the same one that was working at
http://localhost:3000 with real-time records and a real WhatsApp QR.

REQUIREMENTS
------------
1. Node.js installed (v18 or newer): https://nodejs.org
2. MySQL running locally (easiest way: install XAMPP or WAMP and
   start the MySQL service), with a database named `visitor_db`
   created (use phpMyAdmin: Databases → Create database → name it
   visitor_db).

FIRST-TIME SETUP
-----------------
1. Unzip this folder anywhere, e.g. Desktop\VisitorSystem-Local
2. Open a terminal / command prompt in that folder.
3. Run:
       npm install
4. Check the `.env` file already has your email settings. If it's
   missing, copy `.env.example` to `.env` and fill it in.
5. Start the server:
       npm start
   (or: node server.js)
6. You should see something like:
       Server running on http://localhost:3000

USING IT
--------
- Visitor form:      http://localhost:3000
- Admin dashboard:    http://localhost:3000/admin.html
- WhatsApp setup:     click "WhatsApp QR" in the admin sidebar, then
                      "Open WhatsApp Setup Page", and scan the QR
                      with WhatsApp → Linked Devices → Link a Device.

Submitted visitor forms will appear immediately in the Admin →
Visitor Records list, with live Total/Pending/Approved/Declined
counters.

NOTES
-----
- Keep the terminal window open — closing it stops the server.
- The `.wwebjs_auth` folder (created after first WhatsApp login)
  stores the WhatsApp session so you don't have to re-scan the QR
  every time you restart the server.
- This local version is for testing/demo on one computer. For real
  office use reachable from anywhere, it should be deployed to a
  server that stays on 24/7 (a VPS, for example).
